vellum is a Markdown viewer and editor: one executable of about 3.3 MB for Linux or Windows that shows a file as GitHub renders it (headings, lists and task lists, quotes, code, tables, pictures, links, bold, italic and inline code), reads it again when it changes on disk, and edits its text with Ctrl+E and Ctrl+S. With a file open on Windows 11 it uses about 25 MB of memory and no CPU while idle. This is its first release.

## Downloads

- `vellum-v0.1.0-x86_64-windows.zip`: `vellum.exe` for 64-bit Windows 10 and 11, with `register-windows.ps1`, which installs it for the current user and makes it what opens `.md` and `.markdown` files (`powershell -ExecutionPolicy Bypass -File register-windows.ps1`).
- `vellum-v0.1.0-x86_64-linux.tar.gz`: the `vellum` executable for x86-64 Linux with the [GNU C Library (glibc)](https://www.gnu.org/software/libc/) 2.27 or newer (Ubuntu 18.04, Debian 10, Fedora 28 and later), on an X11 or Wayland desktop. Pictures from the web need [libcurl](https://curl.se/libcurl/), which desktop distributions install.
- `SHA256SUMS`: checksums of both archives.

Each archive also holds the README, the MIT `LICENSE`, and a `licenses` folder with the licenses of the code compiled in: [md4c](https://github.com/mity/md4c), [gesso](https://github.com/wakamex/gesso), [kb_text_shape](https://github.com/JimmyLefevre/kb), [stb](https://github.com/nothings/stb) and [Simple DirectMedia Layer (SDL)](https://www.libsdl.org/) 3, plus SDL's Wayland code on Linux. The [README](https://github.com/wakamex/vellum/blob/v0.1.0/README.md) covers its keys and options.

## Verifying a download

Every asset is attested by the release workflow:

```sh
gh attestation verify vellum-v0.1.0-x86_64-windows.zip --repo wakamex/vellum \
  --signer-workflow wakamex/release-actions/.github/workflows/binary-release.yml
gh release verify-asset v0.1.0 vellum-v0.1.0-x86_64-windows.zip --repo wakamex/vellum
```
